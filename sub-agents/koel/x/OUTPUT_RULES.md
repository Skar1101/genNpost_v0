# X — output rules

These are X-only. They used to be global, which is how tweet mechanics leaked into LinkedIn and
Substack drafts. They apply here and nowhere else.

- **No hashtags.** Not one, unless the instruction explicitly asks for them. Hashtags read as
  amateur on X and suppress nothing but your credibility.
- **Threads:** number every tweet `Tweet 1/`, `Tweet 2/`, and so on. Never number lines *inside* a
  single tweet.
- **Never number lines inside a tweet.** A numbered list inside one tweet reads as a cramped
  listicle; either give each point its own tweet or cut to the one that matters.
- **Motivational posts** must be grounded in Souvik's real story — transplant, the 5 medals,
  building in public. Never a generic inspirational line that could belong to anyone.
- **Engagement posts** always close with: Comment "[KEYWORD]" + follow → I'll DM it (must be
  following). The keyword should be relevant and punchy, not generic.
- **Length is a hard ceiling, not a target.** A short post that runs to 279 characters has usually
  failed — the format rewards compression. Aim well under the cap and leave margin.
- **One idea per post.** X punishes posts that try to make three points. Pick the sharpest and cut
  the rest.
